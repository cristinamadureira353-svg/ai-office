# 已知限制

- 日结标题使用进入下一天后的编号，结束第 1 天可能显示“第 2 天结算”。
- 存档信息中的整数有时显示为 `2.0 天 / 701.0 元`，手动名称也可能包含小数。
- 自动化聊天输入使用拉丁字符；中文显示已检查，真实中文输入法交互仍需实机验证。
- 真实模型名称、接口权限、延迟和额度随供应商变化。离线检查不验证实时账户状态。
- 长时间经济平衡和连续多天真实模型游玩未完成全面验收。
- MiniApp 交互验证在本地 macOS 与隔离浏览器进行；Windows/Linux 的真实 MiniMax 宿主及原生导出包需单独测试。
- 缺少员工 Key 时，相关员工不能提供真实模型输出。至少配置一家员工服务；Jev 可跳过。

0.5.10 公开版已修正复盘发言顺序的消费错误：使用 Jev 返回的完整列表，排除宕机/离职员工，决策等待期间释放游戏锁，并丢弃已被新会议替代的结果。该修复仅在本公开仓库中，现有本地安装未自动替换。
